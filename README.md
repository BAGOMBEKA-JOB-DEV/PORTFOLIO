## Overview

This repository contains the source code for my personal portfolio and professional website, **Resume on the Web**.

The application is designed to provide a comprehensive representation of my professional background, technical experience, projects, skills, and other relevant information through a web-based platform.

Rather than relying exclusively on a traditional PDF resume, this project provides an accessible and continuously maintainable digital portfolio that can be updated as my experience, projects, and technical capabilities evolve.

The repository is publicly available as an open-source project and serves both as my personal portfolio and as a practical demonstration of modern web development technologies and practices.

## Project Background

**Resume on the Web** was started in early **2020** as a personal project to establish a dedicated online presence for my professional work.

A traditional resume is inherently limited in how much information it can communicate and how effectively it can demonstrate technical work. This project addresses that limitation by providing a platform where professional information, projects, technical skills, and other relevant work can be presented in a structured and accessible format.

The website is actively maintained and updated as my professional experience and technical interests develop.

The project also provides an environment for experimenting with modern frontend technologies, improving user experience, evaluating implementation approaches, and maintaining a production-oriented web application.

### Primary Objectives

* Provide a centralized online portfolio and professional profile.
* Present technical experience and selected projects in greater detail.
* Maintain a professional web presence independent of third-party platforms.
* Demonstrate practical experience with modern web development technologies.
* Provide a maintainable codebase that can evolve alongside my career.
* Serve as an open-source reference for developers interested in building similar portfolio applications.

## Technology Stack

### Next.js

The application is built with **Next.js**, a React-based framework that provides the foundation for the application's frontend architecture, routing, rendering, and production build process.

Next.js enables the application to take advantage of modern React development patterns while providing capabilities suitable for production web applications.

**Documentation:** https://nextjs.org/

### Tailwind CSS

**Tailwind CSS** is used for the application's styling and user interface implementation.

Its utility-first approach allows the interface to be developed using a consistent and maintainable styling system while providing flexibility for implementing custom layouts and responsive designs.

**Documentation:** https://tailwindcss.com/

### Vercel

The production application is deployed using **Vercel**, providing the hosting and deployment infrastructure for the website.

**Documentation:** https://vercel.com/

## Running the Project Locally

### Prerequisites

Before running the application, ensure that the following software is installed:

* Node.js
* PNPM

PNPM installation instructions are available at:

https://pnpm.io/installation

### Clone the Repository

```bash
git clone https://github.com/BAGOMBEKA-JOB-DEV/PORTOFOLIO.git
cd PORTOFOLIO
```

### Install Dependencies

Install the project dependencies using PNPM:

```bash
pnpm install
```

### Start the Development Server

Run the development server with:

```bash
pnpm dev
```

Once the server has started, open the local development URL provided by Next.js in your browser.

### Build for Production

To create a production build:

```bash
pnpm build
```

The generated build can then be deployed using a compatible Next.js hosting environment.
